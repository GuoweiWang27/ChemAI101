# ChemAI101 课堂展示升级 · 设计文档

> 状态：已获主人批准（2026-08-25）。实施计划见 `docs/plans/` 下对应文件。
> 上游：本设计基于 `docs/plans/2026-08-25-data-engine-upgrade-plan.md` 完成后的稳定版。

## 1. 背景与目标

ChemAI101 当前被任课化学老师用于课堂反应演示（E2 口径），并有学生课后自学的潜在场景。本轮升级目标：

1. **课堂可靠性**：老师投屏演示时零翻车——核心内容不依赖现场网络与 AI；
2. **演示体验**：投屏可读性（大字号、高对比、逐步展开）；
3. **课后可达**：学生手机扫码/点链接直达同一内容的自学态；
4. **申请叙事**：「以真实课堂为中心的产品迭代」——内容策展由国维+社团整理、任课老师审核把关，化学准确性责任落在人而非 AI（呼应门禁新口径）。

## 3. 双形态信息架构

- **同一反应页，两种皮**：URL 参数 `?mode=present` 进入演示态；普通打开为自学态；分享链接默认自学态；页内「演示」按钮一键切换。
- 不引入路由框架；沿用现有 App.tsx tab 结构扩展。
- 新增第三种入口：**库条目页**（从分子库 tab 或分享链接进入），展示单个策展反应的完整教学视图。

## 4. 课程反应库（本轮核心）

### 数据形态

- `src/data/reactions/` 按章节一文件：`mustate-1-02-na-cl.json` 等（人教版必修第一册第二章 海水中的重要元素——钠和氯 等）。
- 构建时打包进前端 bundle；**运行时不请求**——断网可演示、秒开、零 AI 依赖。

### 条目 schema

```ts
interface CuratedReaction {
  id: string;              // 短 slug，全局唯一，如 "na-h2o"
  chapter: string;         // 如 "必修1·第二章"
  title: string;           // 如 "钠与水反应"
  reactants: string;
  conditions: string;
  equation: string;        // 配平好的方程式
  products: string[];
  mechanismSteps: string[]; // 2–5 步，演示模式逐条展开
  productStructure: MoleculeStructure; // 预生成 3D（来自 PubChem/AI 并经结构层校验）
  smiles?: string;
  reviewed: true;          // 老师签字后才能置 true；构建脚本校验
}
```

### 内容管线

1. 国维+社团成员对照人教版教材整理草稿（CSV→JSON 脚本转换）；
2. 任课老师逐条审核签字（纸质或微信确认均可，留痕归档）；
3. 签字后置 `reviewed:true` 进库；构建脚本拒绝未审核条目。
4. 首批章节优先级：必修第一册第二/三章（Na、Cl、Fe）→ 必修第二册第五/六/七章 → 选择性必修视余量。

### 首批典型反应清单（示例，非穷尽）

钠与水、钠在氯气中燃烧、铁在氯气中燃烧、氢气在氯气中燃烧、氯水漂白（HClO）、铁与水蒸气、铝与氢氧化钠溶液、硫的燃烧、二氧化硫与溴水、浓硫酸与铜、氨的喷泉实验、硝酸与铜、甲烷取代、乙烯加成、乙醇催化氧化等。

## 5. 演示模式规格

- 进入：自学态结果卡/库条目右上「演示」按钮 → `?mode=present&r=<slug>` 或当前分析结果。
- 布局（16:9 投屏）：顶栏（方程式 ≥40px + 条件 + 章节）；左栏机理步骤列表（当前步高亮放大，其余降透明度）；右侧 55% 宽 3D 结构区自动缓旋。
- 交互：←→ 翻步骤、F 全屏、Esc 退出。无侧栏、无装饰元素。
- 视觉规格：正文 ≥28px；深色高对比主题；步骤切换有淡入动画。
- AI 自由探索的结果也可进演示模式（此时校验徽章同步放大显示）。

## 6. 分享链路与移动端

- 每个库条目稳定 URL：`/?r=<slug>`（自学态）。
- 「二维码」按钮：前端本地生成（新增 `qrcode` 一个小依赖，纯离线），学生扫码直达。
- 移动端自适应：单列布局、输入区与 3D 视图上下堆叠、触控目标 ≥44px。
- 分享链接打开时若带 `?r=` 自动加载该库条目；slug 不存在则回退首页并提示。

## 7. 降级与错误处理矩阵

| 场景 | 行为 |
| --- | --- |
| 断网/离线 | 库内反应全部可用；「探索更多」（AI/PubChem）入口提示离线 |
| AI 503/超时 | 库条目不受影响；自由探索沿用现有 busy 文案 |
| 未审核条目 | 数据不进 bundle（构建期拦截），运行时不可见 |
| slug 无效 | 回退首页 + toast 提示 |
| PubChem 结构缺失的条目 | 允许 `productStructure` 为空，演示模式隐藏 3D 区只走机理步骤 |

## 8. 测试策略

沿用仓库四件套惯例（vitest / tsc / build / worker:check）+ 新增：

- 数据完整性测试：遍历 reactions JSON，校验 schema、slug 唯一、`reviewed===true`、机理步数 2–5、结构与化学式元素一致（复用 verify.ts 的重原子比对）；
- URL 解析单测：`?r=` 与 `?mode=present` 组合解析；
- 组件逻辑保持轻测惯例（服务层测 fetch 组装，UI 手工冒烟清单随计划给出）。

## 9. 明确不做（YAGNI）

课堂小测/出题、使用统计、账号体系、教师后台、CMS、路由框架、状态管理库、SSR。二维码外任何分享 SDK。

## 11. 验收标准（部署门禁用）

1. 四件套全绿 + 新增数据校验测试通过；
2. 断网模拟下库内反应完整可演示（DevTools offline）；
3. 手机宽度（375px）下自学态可用；
4. 二维码扫码直达正确反应；
5. 至少 10 条经老师签核的 `reviewed:true` 条目入库；
6. 生产探针：分享链接 200、bundle 含演示模式代码。
