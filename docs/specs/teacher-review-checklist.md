## 必修1·第二章 海水中的重要元素（12 条）

### 1. 钠与水反应　`na-h2o`

- **反应物**：Na + H2O
- **条件**：常温（可加酚酞）
- **方程式**：2Na + 2H2O = 2NaOH + H2↑
- **产物**：NaOH、H2
- **机理/教学步骤**：
  - 钠密度小于水，浮在水面
  - 与水剧烈反应放出气体，熔成闪亮小球四处游动
  - 生成 NaOH 使酚酞变红
  - 本质：活泼金属置换出水中的氢

### 4. 乙酸与乙醇的酯化反应　`acetic-acid-esterification`

  - 加入碎瓷片防暴沸，导管口位于饱和碳酸钠液面上方
  - 产生有芳香气味的油状液体（乙酸乙酯）浮于液面
  - 浓硫酸：催化剂兼吸水剂，提高酯的产率
  - 饱和碳酸钠吸收乙醇、中和乙酸、降低酯的溶解度
