## 必修1·第二章 海水中的重要元素——钠和氯（14 条）

### 1. 钠与水反应　`na-h2o`

- **反应物**：钠、水
- **条件**：常温
- **方程式**：2Na + 2H₂O = 2NaOH + H₂↑
- **产物**：氢氧化钠、氢气
- **机理/教学步骤**：
  - 钠的密度比水小，浮在水面上
  - 反应放热，钠熔成闪亮小球（钠熔点低）
  - 小球四处游动并发出嘶嘶声（生成的气体推动）
  - 向反应后溶液滴入酚酞变红，证明生成碱（NaOH）
  - 收集气体靠近火焰有爆鸣声，证明是 H₂
- **教材页码**：＿＿＿＿

### 2. 钠在氧气中燃烧　`na-o2-heat`

- **反应物**：钠、氧气
- **条件**：点燃
- **方程式**：2Na + O₂ = Na₂O₂
- **产物**：过氧化钠
- **机理/教学步骤**：
  - 将金属钠加热至熔化后接触氧气，剧烈燃烧
  - 发出黄色火焰，生成淡黄色固体过氧化钠（Na₂O₂）
  - 对比记忆：常温缓慢氧化生成白色 Na₂O，燃烧则生成 Na₂O₂
  - 条件不同产物不同的典型例子；Na₂O₂ 中氧为 −1 价
- **教材页码**：＿＿＿＿

### 11. 氯气与水（氯水）　`cl2-h2o`

- **反应物**：氯气、水
- **条件**：常温
- **方程式**：Cl₂ + H₂O ⇌ HCl + HClO
- **产物**：盐酸、次氯酸
- **机理/教学步骤**：
  - 氯气溶于水得到黄绿色氯水，部分与水反应
  - 生成盐酸和次氯酸，该反应可逆
  - 氯水的黄绿色来自其中仍溶解的 Cl₂ 分子
  - 对比实验：干燥氯气无漂白性，氯水能使有色布条褪色
  - 结论：起漂白作用的是 HClO 而不是 Cl₂

## 必修1·第三章 铁 金属材料（4 条）

### 1. 铁与水蒸气　`fe-h2o-steam`

- **反应物**：铁、水蒸气
- **条件**：高温
- **方程式**：3Fe + 4H₂O(g) = Fe₃O₄ + 4H₂
- **产物**：四氧化三铁、氢气
- **机理/教学步骤**：
  - 铁粉与高温水蒸气在硬质玻璃管中反应
  - 湿棉花受热提供持续的水蒸气流
  - 产生的气体用肥皂液收集，点燃肥皂泡有爆鸣声，证明是 H₂
  - 管内黑色固体为四氧化三铁 Fe₃O₄
  - 结论：铁在高温下能与水蒸气反应置换出氢
- **教材页码**：＿＿＿＿

## 必修2·第五章 化工生产中的重要非金属元素（11 条）

### 1. 硫在氧气中燃烧　`s-o2`

- **反应物**：硫、氧气
- **条件**：点燃
- **方程式**：S + O₂ = SO₂
- **产物**：二氧化硫
- **机理/教学步骤**：
  - 硫在空气中燃烧发出微弱的淡蓝色火焰
  - 在氧气中燃烧更剧烈，发出明亮的蓝紫色火焰
  - 生成有刺激性气味的二氧化硫气体
  - 环保操作：集气瓶底放少量水吸收 SO₂ 防止污染空气
- **教材页码**：＿＿＿＿

### 2. 二氧化硫催化氧化　`so2-cat-oxidation`

- **反应物**：二氧化硫、氧气
- **条件**：催化剂·加热
- **方程式**：2SO₂ + O₂ ⇌ 2SO₃
- **产物**：三氧化硫
- **机理/教学步骤**：

### 3. 铜与浓硫酸　`cu-conc-h2so4`

- **反应物**：铜、浓硫酸

### 4. 氮气与氧气　`n2-o2`

- **反应物**：氮气、氧气
- **条件**：放电或高温
- **方程式**：N₂ + O₂ = 2NO
- **产物**：一氧化氮
- **机理/教学步骤**：

### 6. 氨的喷泉实验　`nh3-fountain`

- **反应物**：氨气、水（含酚酞）
- **条件**：常温
- **方程式**：NH₃ + H₂O ⇌ NH₃·H₂O
- **产物**：一水合氨
- **机理/教学步骤**：
  - 挤入少量水，烧瓶内形成红色喷泉

  - 酚酞变红说明氨水显碱性

## 必修2·第六章 化学反应与能量（4 条）

- **条件**：常温
- **方程式**：Zn + H₂SO₄(稀) = ZnSO₄ + H₂↑
- **产物**：硫酸锌、氢气
- **机理/教学步骤**：
